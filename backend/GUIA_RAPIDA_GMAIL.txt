═══════════════════════════════════════════════════════════════
  GUÍA RÁPIDA: Configurar Gmail para Recuperación de Contraseña
═══════════════════════════════════════════════════════════════

CORREO A CONFIGURAR: pepsicomanager@gmail.com

═══════════════════════════════════════════════════════════════
  PASO 1: Activar Verificación en 2 Pasos (Si no está activa)
═══════════════════════════════════════════════════════════════

1. Ve a: https://myaccount.google.com/
2. Inicia sesión con: pepsicomanager@gmail.com
3. Haz clic en "Seguridad" (menú lateral)
4. Busca "Verificación en dos pasos"
5. Si NO está activa → Actívala siguiendo las instrucciones
6. Si YA está activa → Continúa al PASO 2

═══════════════════════════════════════════════════════════════
  PASO 2: Generar Contraseña de Aplicación
═══════════════════════════════════════════════════════════════

1. Ve a: https://myaccount.google.com/apppasswords
   (O desde Seguridad → Verificación en dos pasos → Contraseñas de aplicaciones)

2. Selecciona:
   ┌─────────────────────────────────────────┐
   │ Aplicación: [Correo]                   │
   │ Dispositivo: [Otro (nombre personalizado)] │
   │ Nombre: [PepsiCo Flota Sistema]        │
   └─────────────────────────────────────────┘

3. Haz clic en "Generar"

4. Google te mostrará una contraseña de 16 caracteres:
   Ejemplo: "abcd efgh ijkl mnop"
   
   ⚠️ IMPORTANTE: Cópiala AHORA, solo se muestra UNA VEZ
   ✅ Guárdala en un lugar seguro (notas, documento, etc.)

═══════════════════════════════════════════════════════════════
  PASO 3: Configurar el Archivo .env
═══════════════════════════════════════════════════════════════

1. Abre la carpeta del proyecto
2. Ve a la carpeta: backend/
3. Busca el archivo: .env
   - Si NO existe → Créalo (archivo nuevo de texto)
   - Si existe → Ábrelo con un editor (Notepad, VS Code, etc.)

4. Agrega o actualiza estas líneas:

   ┌───────────────────────────────────────────────────────┐
   │ SMTP_HOST=smtp.gmail.com                             │
   │ SMTP_PORT=587                                         │
   │ SMTP_USER=pepsicomanager@gmail.com                    │
   │ SMTP_PASS=aquí_pega_la_contraseña_de_16_caracteres    │
   └───────────────────────────────────────────────────────┘

   Donde dice "aquí_pega_la_contraseña_de_16_caracteres":
   → Pega la contraseña que copiaste en el PASO 2
   
   Ejemplo:
   SMTP_PASS=abcd efgh ijkl mnop
   (Con espacios funciona, sin espacios también funciona)

5. Guarda el archivo .env

═══════════════════════════════════════════════════════════════
  PASO 4: Reiniciar el Servidor
═══════════════════════════════════════════════════════════════

1. Ve a la terminal donde corre el backend
2. Presiona: Ctrl + C (para detenerlo)
3. Ejecuta: npm run dev
4. Observa los mensajes:
   ✅ Si ves "✅ Correo enviado..." → Todo bien
   ⚠️ Si ves "⚠️ SMTP no configurado" → Revisa PASO 3

═══════════════════════════════════════════════════════════════
  PASO 5: Probar que Funciona
═══════════════════════════════════════════════════════════════

1. Abre la aplicación en el navegador
2. Ve a la página de Login
3. Haz clic en "¿Olvidaste tu contraseña?"
4. Ingresa un email de usuario registrado
5. Haz clic en "Enviar"
6. Revisa el correo: pepsicomanager@gmail.com
   - Bandeja de entrada
   - Carpeta Spam (si no lo ves)
7. Deberías recibir un correo con el enlace para restablecer

═══════════════════════════════════════════════════════════════
  PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════

❌ Error: "SMTP no configurado"
   → Verifica que el archivo .env esté en backend/
   → Verifica que tenga SMTP_USER y SMTP_PASS
   → Reinicia el servidor

❌ Error: "Error de autenticación"
   → Genera una nueva contraseña de aplicación (PASO 2)
   → Actualiza SMTP_PASS en .env
   → Reinicia el servidor

📧 No recibo el correo
   → Revisa la carpeta Spam
   → Espera unos minutos
   → Verifica los logs del servidor
