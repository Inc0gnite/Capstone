## 8. Problemas (Issues)

* **Problemas relevantes surgidos:** 
  Durante el desarrollo se identificaron y resolvieron varios problemas técnicos menores:
  1. **Errores de Validación:** Validación de RUT chileno, patente chilena, email y contraseñas
  2. **Errores de Performance:** Optimización de índices de base de datos, implementación de paginación, optimización de queries
  3. **Errores de Seguridad:** Prevención de SQL injection, XSS, CSRF, implementación de rate limiting
  4. **Problemas de Deployment:** Configuración de CORS, variables de entorno, conexión a base de datos en producción
  5. **Problemas de Email:** Configuración de SMTP, solución de timeouts, configuración de servicios de email
  6. **Issues menores en pruebas:** Problemas identificados durante la fase de pruebas, todos resueltos exitosamente

* **Impacto en el proyecto:** 
  Todos los problemas identificados fueron de bajo impacto y se resolvieron rápidamente sin afectar el cronograma del proyecto. Los problemas técnicos fueron resueltos durante el desarrollo y las pruebas sin generar retrasos significativos.

* **Resoluciones adoptadas:** 
  - **Validación:** Implementación de validaciones robustas con algoritmos específicos (RUT chileno, patente)
  - **Performance:** Optimización de índices, paginación, eager loading, transacciones
  - **Seguridad:** Uso de Prisma ORM (previene SQL injection), React auto-escape (previene XSS), JWT tokens (mitiga CSRF), rate limiting implementado
  - **Deployment:** Configuración correcta de CORS, variables de entorno en Railway y Vercel, conexión estable a Neon
  - **Email:** Configuración exitosa de servicios SMTP (Gmail/Resend), solución de problemas de timeout
  - **Pruebas:** Todos los issues identificados durante las pruebas fueron corregidos antes de finalizar la fase
