# PepsiCo Fleet Management

Plataforma de Gestión de Ingreso de Vehículos - PepsiCo Chile

## Descripción

Sistema de gestión de flota vehicular desarrollado con Node.js, Express, TypeScript, React y PostgreSQL.

## Estructura del Proyecto

- `backend/` - API REST con Express y TypeScript
- `frontend/` - Aplicación React con Vite
- `shared/` - Tipos compartidos entre frontend y backend

## Tecnologías

- **Backend**: Node.js, Express, TypeScript, Prisma, PostgreSQL
- **Frontend**: React, TypeScript, Vite, Tailwind CSS
- **Base de Datos**: PostgreSQL
